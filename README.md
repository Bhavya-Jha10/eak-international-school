# EAK International School — Frontend Assignment

A responsive multi-page school website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About & Academics
- `admissions.html` — Admissions process, FAQ and demo enquiry form
- `facilities.html` — Campus and facilities
- `events.html` — Searchable and filterable sample notices/events
- `contact.html` — Contact information and demo contact form

## Run locally
Open `index.html` in a browser. For a smoother development workflow, use VS Code's Live Server extension.

## Important before submitting
- This is a frontend-only demo, as requested by the assignment. Forms validate in the browser but do not send or store data.
- School details, dates, contact information, stats and notices are fictional placeholder content. Replace or clearly present these as demo content in your submission.
- Images are loaded from Unsplash URLs, so internet access is required to display them.
- Review all content and test every page at mobile and desktop widths before publishing.
- Add your own README details, GitHub repository and (optional) live demo link to the submission form.
